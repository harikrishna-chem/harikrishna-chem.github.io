# Project Instructions

## Writing Posts

When adding or updating a post in `src/writing/`, keep the writing discoverable:

- Include a natural reader-facing `title`.
- Include a search-focused `seoTitle`.
- Include a concise `summary`; this becomes the page meta description and RSS description.
- Include `date` and relevant `tags`.
- Preserve the generated `sitemap.xml`, `robots.txt`, `feed.xml`, and `BlogPosting` structured data behavior.
- Run `npm run build` and verify the generated post, Writing index, sitemap, feed, and robots file before publishing.
